A MFIX é um projeto acadêmico desenvolvido para centralizar e automatizar o controle de estoque, permitindo o gerenciamento das movimentações de entrada, saída e ajustes de produtos. A solução foi integrada a uma **interface interativa**, desenvolvida com **Python, Java, HTML e CSS**, reunindo em um único ambiente as funcionalidades operacionais e analíticas do sistema.

Para garantir a qualidade e a confiabilidade das informações, foram implementados processos de **ETL (Extração, Transformação e Carga de Dados)**, responsáveis pela coleta, tratamento e integração dos dados utilizados nas análises. Também foram desenvolvidos dashboards, indicadores estatísticos e consultas analíticas incorporados à interface, proporcionando uma visão estratégica do comportamento do estoque, das movimentações realizadas e do desempenho dos fornecedores, apoiando a tomada de decisão baseada em dados.

O desenvolvimento do projeto envolveu o levantamento de requisitos, a modelagem do banco de dados relacional, a implementação dos processos de ETL e a integração da interface interativa com os dashboards e recursos analíticos, consolidando uma solução completa para gestão e análise de dados.
